# Provenance

Candidate papers were found in November 2026 using OpenAlex keyword searches (copper redox
mediator, copper electrolyte, Retro Cell) filtered to CC-BY open access, then screened by
title and abstract (`candidates_screen.csv`: DOI, year, screen status, note). Licenses were
checked against the paper's own page, the PDF statement, or the Crossref license record.
Open-access status was checked with Unpaywall. Values were read from the full text
(PDF, or the publisher web page for three records, as noted in `source_read`), then checked
by the author against each paper. A second automated pass confirmed that each recorded number
appears in the paper's text.
The papers themselves are not redistributed.
